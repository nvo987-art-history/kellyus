## About

Kelly Code is a visual culture project by Nicholas Van-Orton (NVO987), focused on the evolution of the Kelly Code from personal identity toward broader cultural systems.

The website presents the Kelly Code project, its conceptual development, related visual culture research, and associated digital identity resources.
